How it works

Jupyter · Python41 commits

A Vietnamese voice assistant for schedules and notes. Every request first identifies and verifies the speaker from their voice; only then is the audio transcribed and acted on. Private notes need a second check: a spoken secret phrase that matches a salted hash stored at enrollment.

  1. Voice command
  2. Speaker ID (ECAPA-TDNN)
  3. Verification
  4. PhoWhisper ASR
  5. Intent (NLU)
  6. Action + TTS reply
  • PhoWhisper-small
  • ECAPA-TDNN embeddings
  • FastAPI
  • React + Vite
  • SQLite
